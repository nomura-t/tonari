# となりの紹介ページ（アーティファクト）

公開先は https://claude.ai/artifact/WEJNTpLH9RGqN1UymshWrN （2026-10-29・非公開。人に見せるときはページの共有から）。`index.html` が公開したページの元、`shots/` が載せた画面の写し（となりの --selftest --snapshot で撮って JPEG に縮めたもの）。

直すときは、同じ会話でなければ Artifact の read で url を読んでから、url を指定して publish する（files に shots/ の5枚）。顔は家のデザインシステムの none（プレゼン用の動くページ）で、色はアプリ自身の配色。数字は 2026-10-29 の手元の試しの実測だけで、画面の写しはすべて同じ日の試しの記録。位置の図の場面はコンセプトマップの答えと、その確かめの判定（2本が確かめ済み・10本中）をそのまま使っている。
